# CellLite 平台使用说明

## 1. 启动与更新
双击同目录“启动网页版.vbs”。浏览器打开本地地址，默认端口8876；若被占用会自动选择其他端口。更新后先关闭旧服务，再启动新版，以新打开的地址为准。需要查看错误日志时使用“双击启动.bat”，按Ctrl+C结束。数据在本机处理。

若提示缺少依赖：在平台目录终端运行 `python -m pip install -r requirements.txt`。当前电脑沿用已有依赖目录，换电脑需安装Python和依赖。

## 2. 功能与验证文件对照
所有验证输入均在“验证输入”目录。保留原列名，使用UTF-8 CSV。

| 功能 | 输入文件 | 操作与核验 |
|---|---|---|
| 自训练并保存 | 01_自训练_带参考编号.csv | 选择自训练，填写模型名称，上传并运行。验证AMI约0.7854，留出AMI约0.7540；训练完成后模型出现在列表 |
| 使用模型预测 | 02_模型预测_无参考编号.csv | 选择随包模型00000001，运行；应有16,436分子、78个分组；没有参考编号，AMI应显示无参考 |
| 预测与评测 | 03_预测评测_带参考编号.csv | 同一模型运行；AMI约0.7540、ARI约0.3900，78个分组 |
| 已有结果分析 | 04_已有结果分析.csv | 工作模式选分析已有预测结果；不重新分割，结果与上一行一致 |
| 无训练空间图聚类 | 05_空间聚类_坐标.csv | 工作模式选运行空间分割，邻居32，分辨率0.01；110个分组，无参考分数 |
| 显微图像分割 | 06_显微分割_9目标.png | 顶部切换显微图像；亮目标、阈值0.85、间距8、面积30；检测9个对象 |
| 模型重命名 | 已保存的任一模型 | 选中模型，输入新名称，点击重命名；刷新列表或重启后名称仍在，模型ID不变 |
| 局部与整体 | 03或04完成分析后 | 滚轮缩放、拖动平移、点击放大局部；整体按钮复位；输入有效分组编号仅显示该组 |
| 图片、表格和报告 | 03或04完成分析后 | 下载当前视图PNG、预测CSV、分组统计CSV、评测JSON、分析报告HTML。报告包含当前视图，先复位可导出整体报告 |
| 显微报告 | 06完成分析后 | 下载完整ZIP，解压后应有report.html、measurements.csv、标号图、二值掩膜、实例标签TIFF、参数与校验文件 |

“预期结果.json”记录实际运行指标；“文件校验.json”记录文件大小与SHA256。不同依赖版本可能有数值差异。示例是功能复现材料，不能当作新的独立泛化证据。

## 3. 自训练工作流
1. 选择“自训练并保存模型”。
2. 在模型名称框填写如“回肠MERFISH_第一版”。
3. 上传01文件或自己的带参考编号分子表。至少包含x、y、features、segmented，也接受raw_cells作为参考编号；可选z。
4. 点击开始，等待训练和评测完成。当前训练期间页面显示处理中，不提供逐轮进度，请勿关闭后台或重复提交。
5. 查看验证AMI与留出AMI，以及是否达到0.7。训练会按空间划分，排除跨分区参考细胞及边界缓冲。
6. 模型保存到models/唯一ID目录。模型包含学习得到的分子对分类器、验证集选择的混合权重与Leiden参数。混合权重为0时表示验证集选择了纯几何回退，不能将该结果描述为学习模型优于几何方法。

没有独立参考细胞编号时，不能进行这里的监督训练，也不能计算AMI。不得把本程序自身的predicted_cells改名作为真实参考来证明精度。

## 4. 命名与下次使用
训练前填写的名称随模型保存。已有模型可在列表选中后填写名称并点击“重命名选中模型”。名称1至80字；名称只是显示标签，不更改模型ID或参数。列表同时显示留出AMI。允许同名，建议使用样本类型和版本号区分。

下次启动选择“使用自训练模型预测”，选名称，再上传同类型数据。只需x、y、features，可选z。基因面板、坐标单位、组织与采集方式应匹配；超过20%未知基因会拒绝预测。备份时复制整个models目录，保留model.joblib和report.json；不要只移动报告文件。

## 5. 输入要求与限制
单个空间任务最多100,000条分子。必须是有效数值坐标，所有轴单位一致；可选z缺省为0。每个训练划分须含足够分子及至少两个参考细胞。训练需要同细胞与跨细胞分子对。样本不足或格式错误会返回提示。

当前空间方法不排除背景，所有分子都会分组。AMI按全部参考前景分子计算，不等于百分比准确率。AMI达到0.7不保证细胞计数正确或细胞类型鉴定正确。

随包模型基于MERFISH ileum的Baysor参考标签，0.7540来自已经查看过的开发空间留出区，不是跨样本盲测。02至04来自该留出区；无标签预测文件也不是新的独立样本。真实新样本需另备人工或可靠参考评测，不能保证都超过0.7。

## 6. 显微图像
支持PNG、JPEG和TIFF首帧，最多1200万像素；默认包含触边对象。阈值系数影响前景范围，种子间距影响粘连拆分，最小面积过滤小对象。先查看整体，再切换原图局部检查。导出测量使用像素单位，未填写物理标定，不应解释为微米。核染图像检测细胞核，并非完整细胞。目前显微模块为阈值与分水岭方法，不提供图像模型自训练。

## 7. 报告、保存与故障处理
空间报告为自动统计报告，HTML可在浏览器打印为PDF；下载报告前选择想保留的整体或局部视图。刷新页面会清除当前分析，但已保存模型和下载文件仍在。

出现map或字段缺失提示通常说明旧后台与新版页面不匹配：关闭旧服务并重启，以新打开页面为准。模型名称读取失败时点击刷新模型列表；若训练未达0.7，应保留未达标结论，并增加可靠标注、扩大数据覆盖后重新训练。

## 真实显微图像验证
验证输入目录的07_真实U2OS细胞核_原始16位.tif是真实Hoechst荧光显微图，来自BBBC039（CC0）。上传显微模块，默认参数预测151对象，参考掩膜156对象。PNG上传预览为归一化展示版；人工参考掩膜不要作为原图上传。详见同目录来源与测试说明。

## 分组轮廓显示
默认显示每个预测组分子坐标的凸包轮廓及编号，可分别开关。缩放、平移、筛选时轮廓同步显示，PNG和HTML报告包含当前轮廓视图。线框仅表示预测分子组的估计范围，可能包围空隙或与其他组重叠，不是真实细胞膜。少于3个非共线点无法围成区域。

## 新接入：回肠NGC基因共定位_v1
在工作模式选择使用自训练模型预测，模型列表选择回肠NGC基因共定位_v1。模型可重命名，重启后仍保留。上传验证输入/08_NGC模型_人工区域7评测.csv，应复现13,632条分子、73个分组、AMI约0.7172；无参考预测文件不计算AMI。模型列表0.7891是5个人工开发区域平均值，不是每次上传保证值。此模型与本地Bering使用清理后的同35394条训练分子，未使用人工评测区域分子训练，但同来源样本和区域已经用于开发，不是跨样本盲测。
该模型使用局部基因共定位特征和ExtraTrees边分类器，25%学习边权与75%几何边权混合，32邻居、分辨率0.006。要求二维投影z=0，超过20%未知基因拒绝预测，未证明优于几何回退。模型预测时使用保存的参数，页面参数输入不可改写模型。旧模型、自训练、显微图像、重命名及导出功能保留。现有自训练入口仍使用原简易训练结构，新的NGC条目为本次外部训练后注册的模型。
